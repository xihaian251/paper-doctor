# What we would like from you

You have never worked on this project, and nobody will answer a question about it while you use it.
That is the point of the session: we are testing the documentation, not you.

Please do these four things, in this order:

1. Read `README.md`.
2. Install Paper Doctor. Either route in that file is fine; `dist/` holds the wheel and the source
   archive if you would rather not download anything.
3. Audit the workspace at `phase3/tabm`, and export the findings as JSON.
4. Fill in `RECORDING_SHEET.md` as you go.

The two things we care about most are:

- every step you had to work out for yourself, that the documentation did not tell you;
- anything about the result that you could not determine from the tool's own output.

Please do not change any file in the kit except your recording sheet, and do not read `src/` — if the
docs only make sense once you have read the implementation, that is the finding.

There is no time limit, and nothing you can break. If you get stuck and give up on a step, write down
that you gave up; a recorded give-up is more useful to us than an improvised workaround.
